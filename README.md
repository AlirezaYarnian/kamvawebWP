# قالب وردپرس حرفه‌ای کامواوب (KamvaWeb Pro WordPress Theme)

این مخزن شامل دو بخش اصلی است:

---

## ۱. پوشه قالب اصلی وردپرس: `kamva-theme/` (تمام فایل‌های PHP)

پوشه `kamva-theme/` شامل **کدهای خالص و کامل قالب وردپرس (PHP, CSS, JS)** است که مستقیماً برای نصب در وردپرس آماده شده است:

```
kamva-theme/
├── style.css                            # معرفی قالب، متادیتا و استایل‌های اصلی RTL
├── functions.php                        # هوک‌ها و فراخوانی ماژول‌های قالب
├── index.php                            # تمپلیت صفحه اصلی
├── header.php                           # سربرگ و متاتگ‌های SEO/OpenGraph
├── footer.php                           # پاورقی و لود ماژول‌ها
├── single.php                           # نمایش پست و نوشته‌ها
├── page.php                             # نمایش برگه سازگار با المنتور
├── archive.php                          # بایگانی و دسته‌بندی‌ها
├── 404.php                              # صفحه ۴۰۴ هوشمند با پیشنهاد خودکار
├── woocommerce.php                      # هماهنگی کامل با ووکامرس
├── readme.txt                           # راهنمای قالب
├── admin/
│   └── theme-options.php                # پنل تنظیمات پیشرفته قالب در پیشخوان
└── inc/
    ├── stability-self-healing.php       # سیستم پایداری و خودترمیمی خطاها
    ├── kamva-store-engine.php           # موتور فروشگاهی، هدرساز و ۱۰ استایل هاور
    ├── ai-core.php                      # هسته هوش مصنوعی داخلی و چت‌بات فروش
    ├── security-all-in-one.php          # فایروال، آنتی لاگین و ضد نفوذ
    ├── file-media-security-scanner.php  # اسکنر امنیتی و مالمیکر فایل‌ها و مدیا با هش
    ├── speed-optimizer.php              # بهینه‌ساز فوق سریع و کش لایت‌هاوس ۹۹/۱۰۰
    ├── seo-engine.php                   # موتور اسکیما، JSON-LD و سئوی پیشرفته
    ├── database-ai-cleaner.php          # پاکسازی و بهینه‌سازی دیتابیس با AI
    ├── smart-config-helper.php          # دستیار پیکربندی و راه‌اندازی
    ├── production-deployer.php          # مدیریت دیپلوی و آپدیت امن
    └── elementor-widgets/
        └── class-ai-sales-bot.php       # ویجت اختصاصی المنتور
```

### 🚀 نحوه نصب در وردپرس:
1. پوشه `kamva-theme` را در مسیر `wp-content/themes/` قرار دهید (یا آن را به صورت فایل zip فشرده کرده و از بخش **نمایش > پوسته‌ها > افزودن پوسته** آپلود کنید).
2. پوسته **KamvaWeb Pro** را فعال کنید.
3. تمام امکانات، تم‌آپشن، اسکنر امنیتی، هسته هوش مصنوعی و هماهنگی المنتور به طور خودکار فعال می‌شوند.

---

## ۲. برنامه وب استودیوی مدیریت و بررسی زنده (Developer Studio & Dashboard)

فایل‌های روت پروژه (`src/`, `server.ts`, `index.html`) مربوط به داشبورد و محیط توسعه تعاملی (React + Node.js) هستند که امکان تست و شبیه‌سازی زنده، ممیزی امنیتی، تولید اسناد خودکار و دانلود فایل فشرده قالب را فراهم می‌کنند.

- برای استخراج مجدد یا بروزرسانی فایل‌های PHP قالب می‌توانید دستور زیر را اجرا کنید:
```bash
npm run export-theme
```
